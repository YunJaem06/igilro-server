# 로컬 건물 검수 지도

후속 [작은 구역 조사](shade-pilot-area-2026-10-26.md)에서 후보 경계·실제 50m 경로·OSM 비교 도형을 추가했다. 후보는 현재 모두 평가 보류다. 해당 문서의 선택적 생성 인자를 사용한다. 최신 전체 테스트는 Python 40개와 Node 6개이며 아래 초기 지도 검증도 포함한다.

실제 공공 건물 14,075개와 OSM 보행도로 1,633개, 서버가 반환한 시험 경로를 단일 HTML로 생성한다. 외부 배경지도·API 키·네트워크 연결 없이 파일 자체를 열 수 있다. 실행 중인 검수 주소는 `http://127.0.0.1:8090/`이며 서버 업무 API 8080과 독립적이다.

## 기능

- 높이 확인 5,585개, 누락 8,490개, 매칭 충돌 5개를 색으로 구분한다. 충돌 5개에는 직접 높이가 있는 2개가 포함되므로 상태 수치를 단순 합산하지 않는다.
- 기본 화면은 시험 경로 500m 이내 1,462개다. 100/250/500m 또는 전체 지역, 높이·PK 대조 상태, 내 검수 상태로 필터링한다. 상단 통계는 스냅샷 전체이며 클릭하면 해당 상태의 전체 지역을 보여 준다.
- 건물명·PNU·원본 ID·대장 PK·후보 주소를 검색한다. 목록은 충돌·높이 누락을 우선하고 경로까지의 가까운 순서로 정렬한다.
- 건물을 클릭하면 GIS/HUB의 높이·면적·층수·사용승인일, 연결/보류 사유, 출처와 원본 식별자를 비교한다. 겹친 도형은 ‘다음 도형 보기’로 바꾼다.
- 지도는 드래그, 휠·확대 버튼, 화살표 키로 이동·확대한다. 키보드 사용자는 검색 결과의 버튼으로 상세에 접근할 수 있다.
- 검수 상태·메모를 브라우저에 자동 저장하고 JSON으로 내보내거나 가져온다. 같은 데이터 버전만 병합하며 최신 메모를 유지한다. 브라우저 저장을 이용할 수 없으면 내보내기로 보관한다. 검수 메모는 건물 높이·도형·DB를 수정하지 않는다.

주변 거리는 경로 선분과 건물 경계 사이의 국지적 지도 투영 근사값이다. 높이를 모르는 건물의 그림자 안전 범위나 실제 그늘 비율을 의미하지 않는다. 높이 확인은 원본 직접 수치가 있다는 의미이며 현장 검증 완료와 다르다. 건물 목록은 불완전하고 그늘 평가는 계속 INCOMPLETE_COVERAGE다.

## 생성과 실행

Python 3.12 표준 라이브러리만 필요하다. 다음 원본들은 Git에서 제외된 로컬 `data/`에 있어야 한다. 새 환경에서는 공공 자료 수집·검증과 실제 경로 검색을 먼저 수행한다.

```powershell
python scripts/build-building-review.py --snapshot data/public-buildings/seoul-forest-matching-v2-20261026 --route data/public-buildings/matching-verification-20261026/daylight-response.json --roads data/osm/seoul-forest-20261025.osm --response-cache data/public-buildings/seoul-forest-20261026/responses --output data/review/building-map-20261026/index.html
python scripts/serve-building-review.py --html data/review/building-map-20261026/index.html --port 8090
```

완성된 출력은 기본적으로 덮어쓰지 않는다. UI/원본 갱신 시 새 출력 파일을 생성한다. 브라우저에서 `http://127.0.0.1:8090/`을 연다. 생성한 HTML을 직접 열어도 되지만 브라우저별 파일 URL의 저장 정책이 달라, 메모를 같은 origin에서 유지하려면 위 로컬 주소를 권장한다. `localhost`와 `127.0.0.1`, 포트가 달라지면 메모 저장 영역도 달라질 수 있다. 이동 전 JSON으로 내보낸다.

검수 서버는 127.0.0.1에만 바인딩하고 `/`, `/index.html`에서 지정한 HTML 하나만 제공한다. `.env`, 원본 폴더, 스크립트, 디렉터리 목록이나 수정 API를 제공하지 않는다. 중지는 실행 터미널에서 Ctrl+C다. 이번 숨김 실행 PID는 `.gradle/local-server-run/building-review-server.pid`에 기록했다. PID를 사용할 때는 실제 명령이 검수 서버인지 확인한 뒤 종료한다.

## 입력과 메모 보호

생성기는 적재 파일 SHA-256, 원본 캐시 체크섬, 매칭 높이·식별자, 실제 응답의 건물 버전을 대조한다. WGS84 범위와 닫힌 링도 확인한다. 원본에서 필요한 공개 필드만 추출하며 키나 `.env`를 읽지 않는다. 외부 연결을 차단한 CSP를 포함하고 건물명·메모를 HTML로 실행하지 않는다.

메모 JSON은 `schemaVersion=1`, 정확한 `dataVersion`, `records`를 사용한다. 각 레코드의 `id/status/note/updatedAt`만 허용하며 알 수 없는 건물, 중복 ID, 지원하지 않는 상태, 2,000자를 넘는 메모, 유효하지 않은 시각은 거부한다. 파일은 100MB 이하, 레코드는 해당 스냅샷 건물 수 이하다. 가져온 `height`나 `polygons` 같은 필드는 적용하지 않는다.

## 검증

Python 데이터 준비·검수 입력 테스트 32개와 Node 검수 메모 테스트 6개가 통과했다. CI에도 메모 테스트와 JavaScript 구문 검사를 연결했다. 이번 변경은 로컬 검수 도구이며 JVM 코드·업무 API·서비스 데이터는 변경하지 않았다.

실제 브라우저에서 다음을 확인했다.

- 전체 14,075개/누락 8,490개/충돌 5개 표시와 기본 경로 주변 1,462개.
- 충돌 필터 5개, PK `1005122493` 검색 결과 1개.
- 김동진빌딩의 GIS 3층·10.7m와 HUB 후보 4층·13.3m 비교, 연결 보류 사유.
- 검수 상태·메모 저장, 새로고침 후 유지, JSON 다운로드 후 같은 파일 재가져오기.
- 지도 파일 요청 200, `/.env`, `/../.env`, `/scripts/building_sources.py` 요청 404.

예시 검수 메모 하나를 실제 충돌 건물에 남겼고 `Downloads/igilro-building-notes-282cf56203.json`으로 내보냈다. 이는 원본 높이를 변경하는 승인이 아니다. 결과 화면은 로컬 `data/review/building-map-20261026/review-map.png`에 보관했다.
