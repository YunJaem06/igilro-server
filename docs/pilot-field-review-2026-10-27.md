# 서울숲 작은 구역: 공공 원본 재검증과 현장 확인 지정

후속 [공공 지형·3D 건물 대조](public-spatial-pilot-2026-10-27.md)에서 실제 DEM과 건물 모델을 확보했다. 아래 40.81m는 같은 지면을 가정한 이전 부분 진단 기록이며, 이후 확인된 건물·보행로 표고 차이를 반영한 전체 평가 결과가 아니다.

2026-10-27에 성수중·고등학교 서쪽 보도의 50m 구간을 첫 현장 확인 대상으로 지정했다. 공공 원본 재조회, 태그를 보존한 소구역 그래프 준비, 실제 보행 API와 직접 높이의 그림자 연산까지 확인했다. **현장 사진·답사·측량 자료는 없으며, 실제 그늘 경로 성공 응답은 아직 제공할 수 없다.** 건물 목록·높이 상한·지상 환경을 확인한 것으로 표시하지 않았다.

후속 요청에 따라 **현장 방문은 필수 조건에서 제외하고 공공자료 기반 검증으로 진행**한다. 아래 A0~A5와 현장 기록은 선택적인 정확도 평가 자료다. 현재 보류 이유는 현장 방문 부재 자체가 아니라, 필요한 건물·높이·지형·구조 근거를 아직 확보하지 못한 점이다. [공공자료 기반 진행 기준](phase-4-shade-routing.md#공공데이터만으로-진행하는-순서)을 따른다.

[현장 확인 약도](http://127.0.0.1:8091/)에는 A0~A5 지점, 학교 건물 B1~B5, 비교가 필요한 OSM 도형, 제외한 지하 통로를 표시한다. 항공사진을 대신하는 측량 결과가 아니라 원본 좌표로 그린 약도다. 정적 HTML은 `data/public-buildings/pilot-field-review-20261027/field-review.html`에 있다.

## 현장에서 확인할 구간

OSM `way/1212822987`의 보도 일부다. 원본 태그는 `highway=footway`, `footway=sidewalk`이며 surface·표고·평탄 여부를 확인하는 속성은 없다. 태그에 bridge/tunnel이 없다는 이유만으로 지상 보도로 승인하지 않는다.

| 지점 | 경도 | 위도 |
| --- | ---: | ---: |
| A0 시작 | 127.0373317 | 37.5481620 |
| A1 | 127.0373922 | 37.5482382 |
| A2 | 127.0374527 | 37.5483144 |
| A3 | 127.0375132 | 37.5483906 |
| A4 | 127.0375737 | 37.5484668 |
| A5 끝 | 127.0376341 | 37.5485429 |

WGS84 `[경도, 위도]`이며 지점 사이는 약 10m다. 실제 서버 경로는 50.0m / 36초다. A0→A5를 걸으며 각 지점의 앞뒤 방향 사진·관찰 시각과 위치, 보도 연결, 계단·경사·고가/데크·지하/실내·통행 차단·공사 여부를 기록한다. 지상 구조 확인과 정량적인 표고·경사 측정은 구분한다. 사진이 평평해 보인다는 사실만으로 평면 모델의 정확도를 확정하지 않는다.

학교 쪽 건물 외곽이 약도와 다른 지점은 사진·위치·건물 이름을 함께 기록한다. 외부에서 관찰할 수 있는 자료와 합법적으로 제공받은 도면을 사용하며 사진·층수만으로 건물 높이를 만들지 않는다. 기록용 `field-observations.template.json`은 확인되지 않은 항목을 전부 null/false로 제공한다. 이 기록의 범위는 50m이며 전체 소구역 그래프나 건물 목록을 승인하지 않는다.

## GIS·건축HUB·주소 도형 재조회

기존 키로 약 200m 범위의 GIS 건물 31행, 도로명주소 건물 도형, 4개 필지의 건축HUB 표제부 16행을 조회했다. 전체 원본 응답은 6개이며 첫 GIS 응답 1개를 캐시로 재사용한 뒤 5개를 추가 조회했다. 마지막 재현은 인증정보를 제거한 캐시를 검증하는 offline 실행으로 외부 요청 0회였다. 원본 수집 시각과 원본의 갱신·조사 시각을 구분한다.

| 필지 PNU | HUB 표제부 행 |
| --- | ---: |
| 1120011400106850143: 학교 | 5 |
| 1120011400106850124 | 11 |
| 1120011400106850020 | 0 |
| 1120011400106930000 | 0 |

0행은 해당 필터의 조회 결과일 뿐 실제 건물 없음·높이 0·전체 건물 목록 완전성의 근거가 아니다. 4개 필지 밖의 HUB는 이번에 다시 조회하지 않았으며 `HUB_PARCEL_NOT_REFRESHED`로 구분한다.

네 건물의 직접 높이와 공식 PK·필지·속성 대조는 일치했다. 이는 공공 원본끼리의 일치이며 현장 실측 완료를 뜻하지 않는다. 정보센터는 두 원본의 높이 값이 0/누락 상태이므로 UNKNOWN을 유지한다. 기존 ACTUAL/LEVEL_ESTIMATED/OSM/UNKNOWN 구분을 유지하고 추정 높이를 추가하지 않았다.

반경 100m에는 GIS 3행·주소 도형 5행이 남는다. OSM 도형 `way/1212822991`의 GIS 덮임은 약 2.55%, `way/476442525`는 약 83.24%다. 이름·층수·분할 방식도 달라 높이를 주소/OSM 도형에 자동 전이하지 않았다. B5의 직접 높이·도면, 이 두 도형의 실제 건물 식별과 외곽 대조가 필요하다. 기존 500m 조사 범위의 높이 미확인 301행과 미검증 상한도 그대로다.

## 소구역 보행 그래프 준비

처음에는 약 200×200m 범위의 45개 보행 edge를 조사했다. `way/1212822985`의 `tunnel=yes`, `layer=-1` 구간 1개를 제외했다. 원본 전체 way·node 참조와 surface/구조 태그를 보존한 XML을 생성하고 **서버의 실제 OsmGraphReader 및 WalkingGraph 불변식으로 52개 노드·44개 edge를 검증**했다. 원본 way/from/to 쌍도 활성 서울숲 그래프와 일치한다. 좌표를 새로 만들거나 서로 다른 OSM 노드를 임의 연결하지 않았다.

다만 이 범위는 연결 성분 8개, 무방향 cycle rank 0이다. 순환 경로가 없는 첫 구역은 그늘 평가 확인용이며 그늘진 우회 선택의 효과를 입증할 수 없다. 제한적으로 범위를 비교한 결과는 아래와 같다.

| 검토 사각형의 대략적인 반폭 | 노드 | edge | 연결 성분 | cycle rank |
| --- | ---: | ---: | ---: | ---: |
| 100m | 52 | 44 | 8 | 0 |
| 125m | 72 | 63 | 9 | 0 |
| 150m | 119 | 111 | 10 | 2 |
| 200m | 195 | 192 | 8 | 5 |
| 250m | 269 | 269 | 8 | 8 |

대안 검토용으로 약 300×300m 범위도 별도 XML로 준비했다. 구조상 제외 구간 3개를 제거한 **119개 노드·111개 edge**를 서버 파서로 확인했다. cycle rank는 무방향 연결 구조의 진단이며, 특정 출발·도착의 합법적 대안·30% 우회 한도·그늘 우위를 보장하지 않는다. 대안 경로의 지상 환경 검증 범위도 A0~A5보다 넓어져야 한다.

두 그래프는 모두 **미적재·미활성·groundVerified=false**다. 서울숲 전체 그래프를 지상 검증 목록에 넣지 않았다.

- 200m 검토 그래프: `osm-v1-23ea5ceef399a0d9deaedd9749ee9a9e54e5393cfc66bb256b6dc69fd037fe4f`
- 300m 비교 그래프: `osm-v1-e5e9f0fc01f28ff05acc72e2d91b959f6d86a16eb07235a1b42ad1c40e6fbe35`

실제 운영 준비를 위해 겹치는 서비스 지역 중 출발·도착을 모두 포함하는 가장 작은 bounds의 그래프를 먼저 고르도록 수정했다. 소구역을 적재해도 넓은 `seoul-forest`가 이름 정렬 때문에 계속 선택되는 문제를 방지한다. 소구역을 벗어나면 큰 지역을 선택하고, 선택한 소구역이 단절돼 있으면 넓은 그래프로 조용히 우회하지 않는다. 새 소구역은 아직 활성화하지 않아 현재 실제 경로 동작은 유지한다.

## 실제 경로와 직접 높이의 그림자 연산

새 JAR로 서버를 실행해 health/DB UP을 확인했다. 이 50m 구간에 2026-10-28의 시각을 지정해 실제 API와 PostGIS 연산을 확인했다. 아래 마지막 열은 **직접 높이가 있는 건물만의 정적 그림자와 겹친 길이**이며 전체 그늘 비율·현장 관측·날씨 예측이 아니다.

| 출발 시각 KST | fastest | API 그늘 상태 / 비율 | 알려진 건물 그림자의 교차 길이 |
| --- | --- | --- | ---: |
| 08:00 | 200, 50.0m / 36초 | INCOMPLETE_COVERAGE / null | 약 40.81m |
| 09:00 | 200, 50.0m / 36초 | INCOMPLETE_COVERAGE / null | 0m |
| 12:00 | 200, 50.0m / 36초 | INCOMPLETE_COVERAGE / null | 0m |
| 15:00 | 200, 50.0m / 36초 | INCOMPLETE_COVERAGE / null | 0m |

08:00 모델의 교차 건물은 B1 교사동(직접 높이 22.5m)이다. 현장 대조 때는 건물에서 생긴 그림자의 경계·방향과 시각을 기록하고 나무·구름의 그늘과 구분해야 한다. 미확인 건물을 뺀 결과이므로 40.81m를 전체 그늘 비율로 나누거나 0m를 실제 그늘 없음으로 해석하지 않는다. 건물·지형·관측의 오차도 검증 전이다.

실제 `mode: shade` 요청은 여전히 **503 SHADE_DATA_UNAVAILABLE**다. 오류 code/requestId/헤더 연결을 확인했고, 전체 그늘 비율·평가 가능 지역을 만들지 않았다. 활성 그래프·건물은 기존 버전을 유지한다.

## 추가 근거 확보

원본 정보센터 높이·형상 식별, 물리적 건물 목록과 주변 높이 상한, 지상·표고 근거가 필요하다. [서울시 S-Map 설명](https://news.seoul.go.kr/gov/archives/528155?listPage=1)은 건축물·지형·교량 등 자료를 안내하고 [표고 측정 사용 안내](https://smap.seoul.go.kr/point/guide/guide.html)도 있다. 이번 브라우저에서는 지도 로딩 상태에서 해당 지점의 측정·거리뷰 근거를 확보하지 못했다. 제공 파일·사용 권한이 확보되지 않은 3D 자료를 임의로 추출하거나 높이로 간주하지 않았다. [공식 오픈랩](https://openlab.eseoul.go.kr/)의 자료 제공 경로도 후속 확인 대상이다.

현재 확보한 근거만으로 검증 조건을 true로 바꿀 수 없어 `SHADE_GROUND_VERIFIED_DATASETS`는 비워 둔다. 현장 자료 대신 공식 원격 관측·건물·지형·도로 자료로도 필요한 근거를 보완할 수 있다. A0~A5 또는 일부 자료의 확인으로 전체 111개 구간이나 건물 목록을 승인하지 않는다. 근거를 확보한 범위만 확정해 건물·그래프를 적재하고 AVAILABLE 및 실제 shade 성공을 검증하는 단계가 남아 있다.

## 재현과 검증

```powershell
python scripts/audit-shade-pilot.py --plan data/public-buildings/pilot-area-final-20261026/report.with-routes.json --snapshot data/public-buildings/seoul-forest-matching-v2-20261026 --roads-osm data/osm/seoul-forest-20261025.osm --osm-buildings data/buildings/seoul-forest-osm-20261025.incomplete-provenance.geojson --output data/public-buildings/new-pilot-audit
```

기본 실행은 명시적인 외부 재조회다. 이번 캐시를 재현할 때는 `--offline --response-cache data/public-buildings/pilot-ground-audit-20261027/responses`를 추가한다. 300m 비교 그래프는 `--graph-radius 150`, 출력은 새 폴더를 지정한다.

산출물은 `data/public-buildings/pilot-field-review-20261027/`의 audit.json, ground-review.geojson, field-review.html/png, field-observations.template.json, buildings.pending-review.geojson, roads.pending-review.osm, graph-reader-verification.json, graph-preview-summary.json, topology-scopes.json, live-verification.json, model-0800/0900/1200/1500/ 및 routing-preview-150m/에 있다. 원본·파생 자료는 Git에서 제외한다. 키·인증 URL은 로그·HTML·캐시에 저장하지 않는다.

작은 bbox를 한 번에 조회할 때 GIS 수집기의 건수 변수가 행별 중복 개수에 덮어써져 정상 응답을 불일치로 거부하는 오류를 발견해 수정했다. 2개 건물이 있는 단일 bbox 회귀 테스트를 추가했다. 큰 기존 스냅샷을 다시 적재하거나 변경하지 않았다.

최종 JVM **142개**(단위·아키텍처 108, PostGIS 통합 34), Python **49개**가 통과했다. 원본 페이지네이션·필지 필터 무시·빈 응답·태그/노드 참조·스냅샷 보존·HTML 이스케이프·미검증 표시·겹치는 지역 우선 선택과 기존 회귀 검증을 포함한다. 실제 API 5건과 부분 그림자 연산 4건, 브라우저의 약도·좌표·높이 미확인 표시도 확인했다. Node/지도 메모 코드는 변경하지 않아 기존 Node 테스트를 반복하지 않았다.
